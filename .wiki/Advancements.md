# 🏆 Advancements & Absence Scope

| Parameter | Specification |
| :--- | :--- |
| **Custom Advancement JSONs** | `0` (None Registered by Design) |
| **Advancement Tree Scope** | Unaltered Vanilla & Modded Advancement Trees |
| **Client-Server Separation** | `100%` Client-Side UI Reorganization |
| **Vanilla Parity** | Full compatibility with all Minecraft achievements |

---

## 📖 Absence Policy Mandate

> [!NOTE]
> **Zero Custom Advancements**: Collapsible Game Rules is a client-focused UI enhancement mod designed to streamline menu interactions. It does **not** register custom advancement trees or achievements in `src/main/resources/data/` or trigger custom criteria.

---

## 🎮 Compatibility with Vanilla Advancements

The mod does not intercept or mutate server world criteria. Players can configure game rules using Collapsible Game Rules in their worlds without worrying about breaking vanilla advancement progress or disabling achievements.
