# 🏆 进度与范围说明

| 参数 | 规格说明 |
| :--- | :--- |
| **自定义进度 JSON** | `0` (依架构设计不注册任何进度) |
| **进度树影响范畴** | 原版与模组自定义进度树均完全不受影响 |
| **客户端/服务端架构隔离** | `100%` 纯客户端界面重构 |
| **原版对齐度** | 完全兼容所有 Minecraft 成就与进度解锁 |

---

## 📖 缺失策略强制规范

> [!NOTE]
> **零自定义进度**：Collapsible Game Rules 是一款专注于界面交互体验的客户端辅助模组。本模组**不会**在 `src/main/resources/data/` 中注册任何自定义进度树或成就，亦不会触发任何自定义进度准则。

---

## 🎮 与原版进度的兼容性

本模组完全不拦截或修改服务器世界标准。玩家在世界中使用可折叠游戏规则界面调整参数，绝不会破坏原版进度完成状态或禁用成就解锁。
