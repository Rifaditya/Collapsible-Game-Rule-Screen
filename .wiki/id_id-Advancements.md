# 🏆 Kemajuan & Cakupan

| Parameter | Spesifikasi |
| :--- | :--- |
| **JSON Kemajuan Kustom** | `0` (Tidak ada yang didaftarkan secara sengaja) |
| **Pengaruh pada Pohon Kemajuan**| Pohon kemajuan Vanilla dan mod tetap utuh tanpa modifikasi |
| **Pemisahan Klien/Server** | Penataan ulang grafis antarmuka `100%` di sisi klien |
| **Kepatuhan Vanilla** | Kompatibel penuh dengan seluruh sistem advancement Minecraft |

---

## 📖 Kebijakan Ketiadaan Kemajuan

> [!NOTE]
> **Nol Kemajuan Tambahan**: Collapsible Game Rules adalah mod murni antarmuka klien. Mod ini **tidak menambahkan** pohon kemajuan kustom pada `src/main/resources/data/` dan tidak memicu ataupun menghabiskan kriteria advancement.

---

## 🎮 Kompatibilitas dengan Kemajuan Vanilla

Mod tidak mengganggu pemicu dunia server apa pun. Pemain dapat dengan bebas menyesuaikan aturan permainan melalui layar tanpa khawatir mengganggu pencapaian prestasi dunia Vanilla mereka.
