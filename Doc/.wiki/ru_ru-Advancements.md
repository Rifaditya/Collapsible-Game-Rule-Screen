# 🏆 Достижения и область действия

| Параметр | Спецификация |
| :--- | :--- |
| **Пользовательские JSON достижений** | `0` (Не регистрируются по архитектурному замыслу) |
| **Влияние на деревья достижений** | Ванильные и модифицированные деревья полностью неизменны |
| **Разделение клиент/сервер** | `100%` Реорганизация интерфейса только на стороне клиента |
| **Совместимость с ванилью** | Полная совместимость со всеми достижениями Minecraft |

---

## 📖 Регламент отсутствия достижений

> [!NOTE]
> **Ноль пользовательских достижений**: Collapsible Game Rules — это клиентский мод для улучшения взаимодействия с меню. Он **не** регистрирует пользовательские деревья достижений в папке `src/main/resources/data/` и не активирует специальные триггеры.

---

## 🎮 Совместимость с ванильными достижениями

Мод не перехватывает и не изменяет серверные критерии мира. Игроки могут настраивать правила игры через Collapsible Game Rules, не опасаясь сбоев в прогрессе ванильных достижений.
