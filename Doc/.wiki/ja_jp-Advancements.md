# 🏆 進捗と適用範囲

| 項目 | 仕様 |
| :--- | :--- |
| **カスタム進捗 JSON** | `0` (設計上、登録なし) |
| **進捗ツリーへの影響** | バニラおよび Mod の進捗ツリーは一切変更されません |
| **クライアント/サーバー分離** | `100%` クライアントサイド UI 調整 |
| **バニラ互換性** | すべての実績および進捗システムと完全な互換性を維持 |

---

## 📖 進捗非登録ポリシー

> [!NOTE]
> **進捗の完全な非登録**: Collapsible Game Rules は、クライアントの操作性と視覚的整理に特化した Mod です。`src/main/resources/data/` に進捗ツリーを追加することは一切なく、進捗トリガーを消費または改変することもありません。

---

## 🎮 バニラ進捗との互換性

当 Mod はサーバー側のワールドトリガーを妨害しないため、プレイヤーはゲームルール画面を自由に調整しながら、バニラの進捗を正常に達成することができます。
