# 🏆 進度與範圍說明

| 參數 | 規格說明 |
| :--- | :--- |
| **自訂進度 JSON** | `0` (依架構設計不註冊任何進度) |
| **進度樹影響範疇** | 原版與模組自訂進度樹均完全不受影響 |
| **客戶端/伺服端架構隔離** | `100%` 純客戶端介面重構 |
| **原版對齊度** | 完全相容所有 Minecraft 成就與進度解鎖 |

---

## 📖 缺失策略強制規範

> [!NOTE]
> **零自訂進度**：Collapsible Game Rules 是一款專注於介面互動體驗的客戶端輔助模組。本模組**不會**在 `src/main/resources/data/` 中註冊任何自訂進度樹或成就，亦不會觸發任何自訂進度準則。

---

## 🎮 與原版進度的相容性

本模組完全不攔截或修改伺服器世界標準。玩家在世界中使用可折疊遊戲規則介面調整參數，絕不會破壞原版進度完成狀態或停用成就解鎖。
