# 🏆 Fortschritte & Abgrenzung

| Parameter | Spezifikation |
| :--- | :--- |
| **Benutzerdefinierte Fortschritts-JSONs** | `0` (Aus architektonischen Gründen nicht registriert) |
| **Auswirkung auf Fortschrittsbäume** | Vanilla- und Mod-Bäume bleiben vollständig unverändert |
| **Client/Server-Trennung** | `100%` Reine UI-Neustrukturierung auf Clientseite |
| **Vanilla-Parität** | Vollständige Kompatibilität mit allen Minecraft-Erfolgen |

---

## 📖 Mandat der Abgrenzungsrichtlinie

> [!NOTE]
> **Keine benutzerdefinierten Fortschritte**: Collapsible Game Rules ist eine reine Client-Mod zur Verbesserung der Menübedienung. Sie registriert **keine** Fortschrittsbäume unter `src/main/resources/data/` und löst keine benutzerdefinierten Kriterien aus.

---

## 🎮 Kompatibilität mit Vanilla-Fortschritten

Die Mod fängt keine Kriterien auf dem Server ab. Spieler können die Spielregeln anpassen, ohne den regulären Fortschritt bei Vanilla-Errungenschaften zu gefährden.
