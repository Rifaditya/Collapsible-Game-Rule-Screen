# 💬 Команды Brigadier и область действия

| Параметр | Спецификация |
| :--- | :--- |
| **Пользовательские команды Brigadier** | `0` (Не регистрируются по архитектурному замыслу) |
| **Архитектура команд** | Исключительно клиентский графический интерфейс (GUI) |
| **Ванильное соответствие команд** | `100%` Полная совместимость с ванильной командой `/gamerule` |
| **Доступ к GUI в игре** | Одиночная игра: Создать мир $\to$ Правила игры \| Меню паузы $\to$ Правила игры |

---

## 📖 Регламент отсутствия команд

> [!NOTE]
> **Ноль серверных команд**: В соответствии с философией мгновенного отклика (**Instant Gratification**), **Collapsible Game Rules** не регистрирует команды чата (например, `/collapsiblegamerules reload` или `/cgr config`). Все управление категориями и настройками осуществляется интерактивно прямо на экране меню с немедленной визуальной обратной связью.

---

## 💻 Совместимость с ванильными командами

Поскольку мод построен поверх стандартного `AbstractGameRulesScreen`, любые изменения через чат полностью синхронизируются с экраном:

### Распространенные ванильные команды `/gamerule`

```bash
# Переключить разрушение блоков мобами (взрывы криперов)
/gamerule mobGriefing false

# Сохранять инвентарь после смерти
/gamerule keepInventory true

# Скорость случайных тиков (рост растений)
/gamerule randomTickSpeed 10

# Отключить смену дня и ночи
/gamerule doDaylightCycle false
```

При повторном открытии экрана правил все установленные значения мгновенно отобразятся в соответствующих сворачиваемых категориях.
