# 🏆 Progrès & Portée

| Paramètre | Spécification |
| :--- | :--- |
| **JSON de Progrès Personnalisés** | `0` (Aucun enregistré par conception) |
| **Portée sur les Arbres de Progrès** | Arbres Vanilla et moddés totalement inchangés |
| **Séparation Client/Serveur** | Réorganisation d'interface `100%` côté client |
| **Conformité Vanilla** | Compatibilité intégrale avec tous les succès de Minecraft |

---

## 📖 Mandat de la Politique d'Absence

> [!NOTE]
> **Zéro Progrès Personnalisé** : Collapsible Game Rules est un mod purement axé sur l'ergonomie visuelle du client. Il **n'ajoute aucun** arbre de progrès dans `src/main/resources/data/` et ne déclenche aucun critère particulier.

---

## 🎮 Compatibilité avec les Progrès Vanilla

Le mod n'intercepte aucun critère de monde sur le serveur. Les joueurs peuvent librement ajuster les règles de jeu sans craindre d'interrompre leur progression dans les succès Vanilla.
