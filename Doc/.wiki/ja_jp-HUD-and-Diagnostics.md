# 🖥️ HUD、診断、UI レンダリング

| 項目 | 仕様 |
| :--- | :--- |
| **グラフィック抽出エンジン** | `net.minecraft.client.gui.GuiGraphicsExtractor` |
| **レンダリング対象画面** | `AbstractGameRulesScreen` |
| **ホバー文字色** | `0xFFFFFFAA` (淡いイエロー光沢) |
| **通常文字色** | `0xFFFFFFFF` (クリアホワイト) |
| **ホバー背景** | `0x22FFFFFF` (半透明ホワイト) |
| **境界線** | `0x44AAAAAA` (グレー境界線) |
| **トグル ON 色** | `0x4400FF00` (エメラルドグリーン) |
| **トグル OFF 色** | `0x44FF0000` (ルビーレッド) |

---

## 📖 概要

Minecraft 26.2 において刷新された `GuiGraphicsExtractor` レンダリング方式に完全対応しており、最新のバニラインターフェースデザインと調和した美しいグラフィックを提供します。

---

## 🎨 カラーパレット一覧

| 要素 | ARGB カラーコード | 説明 |
| :--- | :--- | :--- |
| **ホバー背景** | `0x22FFFFFF` | カテゴリヘッダーや操作バーのハイライト。 |
| **区切り線** | `0x44AAAAAA` | リスト内のセクションを分ける落ち着いた線。 |
| **ホバーテキスト** | `0xFFFFFFAA` | カーソルが乗ったときの明るいアクセントカラー。 |
| **通常テキスト** | `0xFFFFFFFF` | 視認性の高いクリアな白。 |
| **ルール数バッジ** | `ChatFormatting.GRAY` | 控えめなグレーで表示されるルール件数。 |
